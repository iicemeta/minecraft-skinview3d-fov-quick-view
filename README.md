# fov-quick-view

皮肤视角标定台。**目的只有一个：把「人物该朝哪边」这个数字量出来。**

站点「小伙伴们」页的弹窗查看器（`club-party-website/src/components/SkinModal/`）默认是
「走路 + 不旋转 + 相机正对镜头」。要改成别的初始朝向，靠嘴描述很容易来回几轮（已经来回过一次了），
所以做成这个工具：你在浏览器里把人物转到满意，复制读数，数字直接落到站点里。

## 跑起来

```bash
cd fov-quick-view
npm install
npm run dev          # http://127.0.0.1:5173
```

## 怎么用

1. **换成要看的皮肤**（可选）：点「本地 PNG」，选你自己那张皮肤图；不换就是站点默认皮肤。
2. **对齐参考图**（推荐）：把要复刻的那张预览图（比如 LittleSkin 的「材质预览」截图）选进「参考图」，
   用「叠加」透明度把它压到人物上 —— 调到能看见轮廓，再转人物去贴合，比来回切窗口用眼睛记准得多。
3. **转人物**：默认「拖拽 = 转人物」。也可以直接拉「人物朝向」滑杆，或按 ±5° / ±1° / ±0.1° 微调，
   数字输入框里能直接填。Shift + 拖动是 0.1°/px 的细调。
4. **选动作**：8 个动作（走路 / 站立 / 跑步 / 飞行 / 挥手 / 潜行 / 受击 / 游泳）+ 4 档速度 +
   自动旋转 + 暂停。站点默认是走路 1×、不旋转。
5. **复制读数**：点「复制」，把整段贴出来即可。想多记几个候选角度就「记一笔」，历史里点哪条复制哪条。

末尾还会附一段能直接粘进 `SkinModal/index.tsx` 的写法和一行 JSON（数字无二义）。

## 为什么读数能直接搬

- **同一个库、同一个版本**：`skinview3d` 精确锁 `3.4.2`（`package.json` 里不带 `^`）。
  相机距离、动画幅度都写在库里，换版本读数就不作数。
- **同一组相机参数**：库默认 `fov 50` / `zoom 0.9` →
  `adjustCameraDistance()` 算出 **距离 43.82**（`4.5 + 16.5 / tan(fov/2) / zoom`）。
  站点弹窗的「重置视角」回的就是这一处。
- **同一组控件口径**：禁平移、`minDistance 14` / `maxDistance 96`、像素密度下限 2 倍。
- **舞台尺寸可以对齐**：左侧「站点弹窗尺寸」= 站点面板 560px 减两侧 0.75rem 内边距 → 舞台 **536px**，
  高 `min(58vh, 460px)`。取景因此和真站一致；「铺满」只是看得更大，不影响角度。

## 两个容易踩的点

- **「转人物」≠「转相机」**。库的 `cameraLight` 是**挂在相机上的**点光源
  （`viewer.ts` 里 `this.camera.add(this.cameraLight)`），转相机时灯跟着走，明暗和转人物不一样。
  站点弹窗只拧 `playerWrapper.rotation.y`，所以要复刻的是「转人物」模式下的那个角度。
- **`resetCameraPose()` 只管相机**，不碰 `playerWrapper.rotation.y`。站点里已经补了这一行；
  在这里点「重置视角」两样都会归位。
