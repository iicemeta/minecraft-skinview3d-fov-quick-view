# fov-quick-view

皮肤视角标定台。**目的只有一个：把「人物该朝哪边」这个数字量出来。**

站点「小伙伴们」页的弹窗查看器（`club-party-website/src/components/SkinModal/`）默认是
「走路 + 不旋转」，取景由一组常量（fov / zoom / 相机方向 / 距离）钉住。要改成别的初始视角，
靠嘴描述很容易来回几轮（已经来回过一次了），所以做成这个工具：你在浏览器里把人物转到满意，
复制读数，数字直接落到站点里。**当前那一组数的来历见文末「已标定」。**

## 跑起来

```bash
cd fov-quick-view
npm install
npm run dev          # http://127.0.0.1:5173
```

## 怎么用

1. **换成要看的皮肤**（可选）：点「本地 PNG」，选你自己那张皮肤图；不换就是站点默认皮肤。
2. **对齐参考图**（推荐）：把要复刻的那张预览图（比如 LittleSkin 的「材质预览」截图）选进「参考图」，
   用「叠加」透明度把它压到人物上 —— 调到能看见轮廓，再转人物去贴合，比来回切窗口用眼睛记准得多。
3. **转人物**：默认「拖拽 = 转人物」。也可以直接拉「人物朝向」滑杆，或按 ±5° / ±1° / ±0.1° 微调，
   数字输入框里能直接填。Shift + 拖动是 0.1°/px 的细调。
4. **选动作**：8 个动作（走路 / 站立 / 跑步 / 飞行 / 挥手 / 潜行 / 受击 / 游泳）+ 4 档速度 +
   自动旋转 + 暂停。站点默认是走路 1×、不旋转。
5. **复制读数**：点「复制」，把整段贴出来即可。想多记几个候选角度就「记一笔」，历史里点哪条复制哪条。

## 为什么读数能直接搬

- **同一个库、同一个版本**：`skinview3d` 精确锁 `3.4.2`（`package.json` 里不带 `^`）。
  相机距离、动画幅度都写在库里，换版本读数就不作数。
- **同一组相机参数**：库默认 `fov 50` / `zoom 0.9` → `adjustCameraDistance()` 算出 **距离 43.82**
  （`4.5 + 16.5 / tan(fov/2) / zoom`）。注意 `fov` / `zoom` 的 setter 都会**重算距离**，
  而它只改距离、**保方向**（`camera.position.multiplyScalar(distance / length)`）——
  所以在标定台里改完 fov 再滚轮推一下，距离就不再是公式值了：**读数里的「距离」永远以那一行为准**。
- **同一组控件口径**：禁平移、`minDistance 14` / `maxDistance 96`、像素密度下限 2 倍。
- **舞台尺寸可以对齐**：左侧「站点弹窗尺寸」= 站点面板 560px 减两侧 0.75rem 内边距 → 舞台 **536px**，
  高 `min(58vh, 460px)`。取景因此和真站一致；「铺满」只是看得更大，不影响角度。

## 已标定：站点弹窗的默认取景（2026-10-15）

用户在此量出并落到站点的一组数（`SkinModal/index.tsx` 顶部那四个常量）：

```
模式      转相机
人物朝向  0.0°    0.0000 rad
相机位置  (-21.99, -1.56, 31.15)     ← 方位角 -35.23°、仰角 -2.34°
距离      38.16    fov 60°   zoom 0.90
画布      536×460 css · 1072×920 buffer (dpr 2)
动作      walk · 1.0× · 播放中 · 自转 off
```

复刻方式：`fov = 60` / `zoom = 0.9`，再把 `camera.position` 置成「上面那个位置的方向 × 38.16」
（**顺序**：先 fov/zoom、后位置 —— 那两个 setter 会重算距离，位置必须最后写）。人物朝向仍是 0。
**注意这次用的是「转相机」**：灯跟着相机走，所以站点里把相机摆过去、与这里的画面完全一致；
若改成「转人物 -35.2°」，朝向一样但明暗不同（见下一条）。

## 两个容易踩的点

- **「转人物」≠「转相机」**。库的 `cameraLight` 是**挂在相机上的**点光源
  （`viewer.ts` 里 `this.camera.add(this.cameraLight)`），转相机时灯跟着走，明暗和转人物不一样。
  所以复刻时要**和读数里的模式保持一致**：这次站点落的是「转相机」那条路（相机位置 + fov/距离）。
- **`resetCameraPose()` 只管相机**，不碰 `playerWrapper.rotation.y`，而且它把相机摆回**库默认**的正面
  （`position.set(0,0,1)` 再 `adjustCameraDistance()`）。站点弹窗的默认取景已经不是库默认了，
  所以「重置视角」不再调它，而是调自己那个 `applyDefaultPose()` —— 否则点一下复位就跳回正面。
  在标定台这里点「重置视角」回的是库默认（正面 + fov 50 / 距离 43.82），不是站点那一处。
